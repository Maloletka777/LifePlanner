# Live Planner на Swift

Новая версия находится в этой папке. Старое приложение сохранено отдельно и остаётся в основной ветке GitHub.

## Что открыть

- **На Mac:** `LivePlanner.xcodeproj` → схема `LivePlanner` для iPhone/iPad или `LivePlannerMac` для Mac → Run.
- **На этом Windows-компьютере:** можно проверять ядро и хранение данных. Нативные экраны SwiftUI здесь не запускаются; для них используются Mac/Xcode или проверки GitHub Actions.
- **GitHub:** [черновик перехода на Swift](https://github.com/Maloletka777/LifePlanner/pull/1). Пока не объединён с основной веткой.

## Резервные копии

Соседняя папка `LivePlanner-Backups-2026-10-18` содержит два проверенных ZIP-архива и JSON-манифесты с SHA-256. Не используйте файл с пометкой `interrupted` — это не завершённая копия. В архивах нет истории с телефона, которой не было среди исходных файлов.

## Важно для перехода

Кандидат использует отдельный идентификатор и базу. Не удаляйте старую установку ради новой: её история пока автоматически не переносится. Сначала нужен экспорт старой базы и проверенный конвертер. Текущее восстановление в Settings работает с резервными JSON-копиями новой Swift-версии.

Для запуска на физическом iPhone потребуется выбрать свою команду подписи в Xcode. Apple Watch, синхронизация, HealthKit и предиктивная модель пока не реализованы. Проверки на симуляторе не заменяют приёмку на телефоне.
