# Проверка iPhone без собственного Mac

Владелец сообщил 18 октября 2026, что Mac нет. Это не препятствует разработке: проект уже собирается и проверяется на облачном Mac в GitHub Actions. Симуляторная сборка не устанавливается на физический iPhone.

Для следующего этапа можно подготовить подписанную сборку на облачном Mac и передать её через TestFlight. Apple требует членство команды в Apple Developer Program для такой доставки. Сначала нужно выяснить, есть ли уже действующая команда владельца или доступ к университетской команде; покупать подписку заранее не требуется.

Порядок подготовки:

1. Завершить автоматические проверки текущего исходного кода.
2. Определить доступную команду Apple Developer и её разрешения. Не передавать пароль Apple ID, ключи и сертификаты в чат или репозиторий.
3. Создать согласованную запись приложения в App Store Connect, назначить идентификатор и настроить подпись через защищённые средства сборки. Нынешний идентификатор является идентификатором кандидата для разработки.
4. Подготовить и проверить архив для реального устройства, загрузить в App Store Connect и дождаться обработки. Создание учётной записи, принятие соглашений и платные действия выполняются владельцем.
5. Установить через TestFlight и пройти физическую приёмку из VALIDATION.md: перезапуск, резервная копия, даты, клавиатуры, доступность и доставка уведомлений.

Никакие сертификаты не созданы, учётные записи не оплачены, сборка в TestFlight не опубликована. Отсутствие такой установки не должно описываться как пройденная физическая приёмка.
